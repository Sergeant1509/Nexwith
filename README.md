# Nexwith website

A responsive static agency website built with HTML, CSS and vanilla JavaScript.

## Included
- User-supplied Nexwith logo
- Editorial typography (Space Grotesk + DM Sans)
- Responsive navigation and mobile contact action
- Animated offer ticker and secondary marquee
- Scroll reveal, subtle hero motion and hover transitions
- Interactive FAQ accordion
- Package/service enquiry prefill
- Email handoff form (mailto)
